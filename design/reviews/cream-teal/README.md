# Cream and teal app screens

5 November 2026. These are screenshots from the running Customer and Manager/Barber
Expo applications at 393 × 852 CSS pixels. The user's supplied cream and teal image
is the current visual reference, replacing the earlier dark prototype.

Customer: [Home](customer-home.png), [salon](salon-details.png),
[calendar](calendar.png), [review request](review-request.png),
[My visits](bookings.png), [queue ticket](queue-ticket.png),
[photo collections](collections.png), [account](account.png),
[sign in](customer-sign-in.png), [sign up](customer-sign-up.png).

Staff: [sign in](staff-sign-in.png), [owner overview](manager-dashboard.png),
[square salon cards](manager-salons.png), [team](manager-team.png),
[invitation](manager-invitation.png), [barber chair](barber-chair.png).

The screen content uses isolated API fixtures. Names, pictures, counts, codes and
financial totals are test values; production continues to use the account's actual
Supabase records. No fixture records were inserted into the hosted project.
Missing venue photos retain an honest placeholder.

The apps share the cream canvas, teal controls, beige accents, rounded cards,
DM Sans type and square salon photos. Appointment requests retain salon confirmation;
haircut prices are entered only after completion. The screenshot set includes
the extra operational screens that are not depicted in the supplied reference.

Native pages and sheets, press/release feedback, tab fades, loading indicators and
OS reduced-motion behavior are implemented. Static browser images do not demonstrate
native transitions, camera permissions, keyboard behavior or Maps handoff; those
remain part of phone acceptance.
